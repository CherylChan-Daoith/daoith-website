# 合规方案生成前必读 · 导读

> **知识库用途**：道一内部合规方案生成必读 / 实操知识整理为 Markdown，供诊断助手检索。规则可能更新，请以现行法规与内部最新制度为准。本文不构成对外法律意见。

> **检索关键词**：合规方案,生成前必读,综合选项,风险提示,解决方案,行动建议,出报告硬约束,出报告流水线

## 出报告流水线（第 1～7 步答完后强制按序）

1. 通读 `15-出报告硬约束与路径要点`（了解写法与要求；须读完整篇）
2. 按用户选项通读 `00-必须知道的知识点` 对应 `##` 块（知识点一至十四 / 类型一至类型六，每块完整可读）
3. 按用户各题答案检索「问题X + 关键词」分篇中的选项注意事项
4. 判定路径 A / B / C / D（勿对用户说出路径名；0退税率或未授权备案商标先走 D）
5. 参考对应【方案样本】路径篇（含 `23` 路径D），按档案改写
6. 生成四章合规诊断报告

请仔细阅读每个问题下不同选项可能引发的风险和对应的解决方案，综合全部选项给出风险提示、解决方案和行动建议。
