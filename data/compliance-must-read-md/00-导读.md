# 合规方案生成前必读 · 导读

> **知识库用途**：道一内部合规方案生成必读 / 实操知识整理为 Markdown，供诊断助手检索。规则可能更新，请以现行法规与内部最新制度为准。本文不构成对外法律意见。

> **检索关键词**：合规方案,生成前必读,出报告硬约束,出报告流水线,report_path,路径Y,路径D,路径X,路径Z,路径C,路径B,路径A

## 出报告流水线（第 1～7 步答完后强制按序）

1. 通读 `15-出报告硬约束与路径要点`（短硬约束与决策树；须读完整篇）
2. 按用户选项通读 `00-必须知道的知识点` 对应 `##` 块（知识点一至十四 / 类型一至类型六，每块完整可读）
3. 按档案判定 `report_path`（顺序命中即停；**勿对用户说出路径字母**）：
   **Y → D → X → Z → C → B → A**
4. **只**检索并整篇采信当前路径的 `30–36-路径*-必读` 一篇（含合规要点与结构样本；禁止照抄样本画像）
5. 生成四章合规诊断报告（或上游要求的 JSON 四键）

| report_path | 文件 | 一句话 |
|-------------|------|--------|
| Y | `30-路径Y-非中国店-必读` | 境外主体店铺 |
| D | `31-路径D-产品无法退税-必读` | 0退税率或商标未授权 |
| X | `32-路径X-特殊平台-必读` | 阿里国际站（大陆主体履约） |
| Z | `33-路径Z-已合规出口-必读` | 已正式报关或 9610/1210 已报关 |
| C | `34-路径C-平台安排出口-必读` | 由平台安排出口 |
| B | `35-路径B-自发货小包-必读` | 小包未报关 |
| A | `36-路径A-备货海外仓-必读` | 委托货代/其他（兜底） |

可选：按需检索 `10–14` 实操附件。旧版「问题1–7」分篇与「20–23 方案样本」已废弃，勿再检索。
