## 特征与子类型

**特征**：

中国店+产品能退免税+非国际站+平台安排出口

**子类型 / 分类**：

- 【C1 速卖通】问题1选**速卖通**，问题3选**全托管（国内仓）** / **半托管（国内仓）**
- 【C2 SHEIN】问题1选**SHEIN**，问题3选** 供货SHEIN（国内仓）**
- 【C3 其他平台】：问题3选**全托管（国内仓）** / **半托管（国内仓）** / **发货到平台国内仓** 等，或第四步已自动记为**由平台安排出口**（问诊时跳过问题4）。
- 判定：中国店 + 产品能退免税 + 非国际站 + 由平台安排出口 → 走 C。

## 风险思路与要点

**【C1 速卖通】**

1. 速卖通平台同一安排9610出口，可与平台确认是否能下载9610报关清单，如果拿不到清单，存在视同内销征税的风险。
2. 若直接按出口免税申报，税局不认可时面临视同内销补税。
3. 无票部分在视同内销下无法抵扣，税负更高。

**【C2 SHEIN】**

1. 大部分商家是供货给SHEIN，目前SHEIN平台可以让这类型商家选择由平台代扣代缴1%的企业所得税，增值税不做处理。非广州的商家需要提前与当地主管税务机关沟通该代扣代缴政策的适用性，避免重复征税的风险。
2. SHEIN外综服报关抬头为外综服公司，**报关单监管方式为9610**；因9610退税审核严格，外综服退税实务上多为税局一事一议，不可默认各地都能办成。
3. 若直接按出口免税申报，税局不认可时面临视同内销补税。
4. 无票部分在视同内销下无法抵扣，税负更高。

**【C3其他平台】**

1. 全托管等模式下通常**不具备**自有抬头正式报关退税条件，退税四条件在「正式报关」这一条上不成立。
2. 若直接按出口免税申报，税局不认可时面临视同内销补税。
3. 无票部分在视同内销下无法抵扣，税负更高。
4. 大陆主体信息报送：平台仍会推送交易信息，须按店铺公司、按订单销售额申报。


## 解决方案思路与要点

开篇写明：全托管/平台国内仓由平台统一安排出口，通常不具备自有抬头正式报关退税条件。

**【C1 速卖通】**

1. 与平台沟通取得9610报关清单并留存好平台订单、物流和支付证据链，跟主管税局沟通免增值税处理，免税处理的情况下，增值税进项税无法退税会变成成本，所以要尽可能拿0%/ 1%/ 3%的增值税普通发票降低成本。
2. 视同内销征税的情况下，如果商家自身是一般纳税人，应尽可能以较低的税点获取供应商增值税专用发票（如供应商可以在无票采购的基础上加成10%，开具13%税点的增值税专用发票），作为进项税抵扣，这样可以一定程度上降低税负。

**【C2 SHEIN】**

1. 优先评估SHEIN外综服退税的模式（外综服报关单**监管方式为9610**），退税成功时综合税负率一般低于1%，优于平台代扣代缴。
2. 无法走通外综服退税时，评估平台代扣代缴，需要确认主管税局认可。
3. **因9610退税审核严格，SHEIN外综服退税才强调一事一议**；平台代扣代缴同样存在跟税局一事一议的不确定性。非广州商家务必提前跟主管税局沟通确认。
4. 即不选择SHEIN外综服也不选择平台代扣代缴的商家，务必留存好平台订单、物流和支付证据链，跟主管税局沟通免增值税处理，免税处理的情况下，增值税进项税无法退税会变成成本，所以要尽可能拿0%/ 1%/ 3%的增值税普通发票降低成本。

**【C3其他平台】**

1. 核实平台实际出口方式与可提供单据（订单、物流、结算、如有报关清单），凭证据链与税局沟通，以平台政策与税局为准，不可断言能免税或退税。
2. 留存订单流、资金流、物流及平台结算单据，尽可能申请免税（不可断言获批）。
3. 难以自有抬头退免税时，按视同内销测算税负（销售额换算不含税×适用税率，进项仅限专票），避免误按出口免税申报。
4. 无票部分争取补开专票，降低视同内销税负；一般纳税人视同内销尽量专票抵扣；若税局同意免税则尽量普票。
5. 税局不认可则评估业务模式重构（如引入境外主体作为平台销售主体），引导专家1v1。

## 方案样本（结构参考·禁止照抄画像）

> **示例样本**（结构参考；禁止照抄下列平台/销售额/画像）

**【诊断档案】**（示例）

- 销售平台：Temu
- 注册主体：中国大陆公司
- 发货方式：全托管（国内仓）
- 出口方式：由平台安排出口
- 供应商发票：部分专票+部分无票
- 产品类别：普货，能正常报关出口和退税
- 年销售额：2000-5000万

**【核心风险诊断】**（示例结构）

业务流程：部分专票+部分无票 → 中国大陆公司 → 由平台安排出口 → 全托管（国内仓） → Temu → 境外消费者
主要风险：当前最大瓶颈是Temu全托管由平台统一安排出口，商家通常不具备自有抬头正式报关，无法满足退税四条件中的「正式报关出口」；无票部分在视同内销下不能抵扣，税负与合规风险较高

01 供应商发票和产品环节
- **专票与无票并存**：有票部分在视同内销时尚可抵扣进项；无票部分既不能退税也不能抵扣，直接抬高税负
- **出口退税率核实**：产品为普货，但本模式通常走不到自有抬头退税。可在本页左侧「查询出口退税率」核实，以备模式调整时使用

02 报关出口环节
- **平台安排出口、无自有报关抬头**：全托管货入平台国内仓后由平台出口，商家难以取得自己为发货单位的报关单，退税路径被阻断
- **误按出口免税申报的补税风险**：在税局不认可平台单据作为免税依据时，可能按视同内销补税

03 境外销售环节
- **提现与收汇限制**：大陆公司Temu店常见仅人民币提现，即使未来想做退税，也可能受收汇条件制约，须先与平台确认
- **平台信息报送**：平台会推送身份与交易信息，收入须按平台订单销售额由店铺公司申报，不得按回款、不得扣除平台费用

**【合规方案】**（示例结构）
您属于Temu全托管国内仓、由平台安排出口，通常不具备自有抬头正式报关退税条件，核心是核实平台单据、用证据链与税局沟通免税，并测算视同内销税负

01 供应商发票和产品环节
- 税局认可免税的情况下，推动无票供应商补开普票（避免专票，无法退税，成本高）
- 税局不认可免税，视同内销口径下尽量取得专票抵扣

02 报关出口环节
- 核实平台实际出口方式与可提供单据
- 留存订单、物流、结算证据链，与税局沟通免税

03 境外销售环节
- 按平台订单销售额确认收入
- 确认平台提现币种是否支持外币
- **平台统一出口与单据核实**：全托管由平台安排出口，向平台索取实际报关方式及可提供给商家的单据，连同订单流、资金流、物流及结算单与主管税局沟通是否认可免税——以平台政策与税局为准，不可断言获批
- **免税和视同内销税负测算**：若难以退税，按视同内销测算（不含税销售额×适用税率，进项仅限专票），无票部分补开专票以降低税负。税局认可免税的情况下，推动无票供应商补开普票（避免专票，无法退税，成本高）
- **提现限制**：大陆公司店铺须先与平台确认能否提现外币；仅人民币提现可能制约退免税收汇
- **税局不认可时的模式评估**：可评估引入境外主体作为平台销售主体，具体需要结合平台入驻和流量等政策，建议引入专家综合评估。
- **平台信息报送**：按订单销售额申报，费用单独核算。

**【行动建议】**（示例）
1. 向Temu索取实际出口方式及可提供的报关/物流/结算单据并归档。
2.与主管税局沟通全托管出口能否免税，不要自行按免税申报。
3. 梳理无票供应商，免税情况下尽量取得普票降低成本，视同内销应优先获取专票。
4. 按视同内销测算税负，评估现有毛利能否覆盖，考虑产品加价覆盖税负。
5. 确认平台提现币种；按平台订单销售额建立申报口径。

**【注意事项】**（示例）
- 本报告为一般性参考，不构成法律意见；具体实施前建议咨询专业财税顾问。
- 单次诊断仅针对当前Temu平台及所提供信息。
- 各地税局对平台安排出口的免税口径差异较大，沟通前可咨询专家。
