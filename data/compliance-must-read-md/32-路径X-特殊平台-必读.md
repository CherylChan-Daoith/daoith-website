## 特征与子类型

**特征**：

中国店+产品能退免税+国际站

**子类型 / 分类**：

- 【X1安全型】：发货/履约为**自营出口** / **一达通代理出口3+N** / **一达通代理出口2+N** / **市场采购出口**。国际站背后有一达通提供报关/退税/收汇一站式履约，前三种须凭报关单收汇→正式报关。
- 【X2高危型】：发货为**便捷发货出口**。平台提现规则多为单个订单金额不超过5000美元、无需报关单结汇、可结汇到法人个人账户，税务合规风险主要集中于此；出口多大概率为小包未报关。
- 判定：中国店 + 产品能退免税 + 平台=阿里国际站 → 走 X（优先于 A/B/C）。0退税率或商标未授权仍先走 D，不进 X。

## 风险思路与要点

**【X1安全型】**

1. 出口履约本身已正式报关，不要写成「尚未出口合规」。主要剩余风险在供应商发票：无法取得发票则合规税负高；仅有普票则无法退税。
2. 一达通3+N要求必须为生产型企业，外购成品不满足视同自产则不能退税、只能免税。
3. 自营出口、一达通2+N、市场采购**不得**默认生产型企业，贸易型企业也可以走。
4. 大陆主体仍有信息报送与按订单销售额申报的问题。

**【X2高危型】**

1. 难正式报关退税（小件利润低、报关费高）。
2. 无报关单 → 视同内销风险；销售额超过约500万人民币可能按13%补缴增值税。
4. 若店铺公司同时为一般纳税人退税企业，无法享受跨境电商企业合规过渡期的核定征收政策，需按照13%计算缴纳增值税，合规税负高。
4. 资金提现至个人账户 → 资金合规风险高。


## 解决方案思路与要点

**【X1安全型】**

1. 提醒依法合规申报纳税即可，方案侧重降剩余风险与税负，勿写成从零搭建出口架构。
2. 无法取得发票 → 宜走市场采购出口，否则税负高；仅能取得普票 → 梳理供应商、争取专票。
3. 架构名称须用「国际站正式报关履约与纳税申报」，禁止改用「0110出口+香港公司」「1039出口+香港公司」。
4. 仅一达通3+N：默认生产型，须核外购是否满足视同自产，不满足则只能免税。
5. 自营/2+N/市场采购：不得默认生产型；贸易型企业按免退税口径。
6. 收入按平台订单销售额确认。
7. 出口退税企业注意备案单证合规性，近年来对于出口退税备案单证的审核越来越严格，企业一定要提前做好备案单证的管理，避免出口退税款被要求返纳。

**【X2高危型】**

按产品分支：①0退税率或商标未授权 → 按路径D口径控税负，禁止1210/9610；②非定制普货/涉检 → 「1210出口备货至保税区」（涉检只能走备货保税仓，一日游/9610商检成本过高）；③定制类普货 → 「1210保税区一日游或9610跨境电商零售出口」。④须写清会改物流、可能增本，评估哪家物流商能走及费用。⑤若评估后小包无法通过1210/9610正式报关，建议咨询财税专家重新评估业务模式。⑥无票+综试区可写无票免征+企税核定（同主体不得既退税又核定）。⑦个人账户收汇须改为公司对公账户。⑧收入按平台订单销售额确认。

## 方案样本（结构参考·禁止照抄画像）

> **示例样本**（结构参考；禁止照抄下列平台/销售额/画像）

**【诊断档案】**（示例）

- 销售平台：阿里国际站
- 注册主体：中国大陆公司
- 发货方式：一达通代理出口3+N
- 出口方式：正式报关出口（0110/9710）（由履约方式直接记入）
- 供应商发票：能提供增值税专用发票
- 产品类别：普货，能正常报关出口和退税
- 年销售额：2000-5000万

**【核心风险诊断】**（示例结构）

业务流程：增值税专用发票 → 中国大陆公司 → 正式报关出口（0110） → 一达通代理出口3+N → 阿里国际站 → 境外客户
主要风险：当前出口已由一达通正式报关履约，最大剩余风险不在「有没有报关」，而在生产型企业外购是否满足视同自产、专票与报关单是否三流一致，以及大陆主体信息报送与收入确认口径

01 供应商发票和产品环节
- **专票可用于退税，但须核视同自产**：一达通3+N只合作生产型企业。若存在外购成品，不满足视同自产条件则不能退税、只能免税
- **出口退税率核实**：产品为普货，须逐项核实HS对应退税率。可在本页左侧「查询出口退税率」核实

02 报关出口环节
- **履约已正式报关**：凭报关单收汇，不要按「委托货代/未报关」去搭海外仓香港架构
- **报关品名与进项一致性**：贸易性外购或进项品名/单位与报关单不一致时，退税易被审核卡点

03 境外销售环节
- **平台信息报送**：国际站店铺为大陆公司，税务机关可掌握交易信息；企业所得税须按平台订单销售额申报，不得按回款、不得扣除平台费用

**【合规方案】**（示例结构）
您属于阿里国际站一达通3+N，出口已正式报关履约，核心是依法合规申报纳税，并核生产型企业退税资格与发票质量

01 供应商发票和产品环节
- 梳理专票与外购成品清单
- 核实HS及出口退税率
- 外购货物核视同自产条件

02 报关出口环节
- 凭报关单收汇并合规申报纳税
- 核对报关品名、单位与进项发票一致
- 做好备案单证管理，特别是货物从工厂到海外买家的全流程物流单据，避免退税款返纳风险

03 境外销售环节
- 按平台订单销售额确认收入
- **国际站正式报关履约与纳税申报**：一达通3+N已提供报关/退税/收汇一站式履约，继续以报关单收汇并申报出口退税（专票）或免税（不满足退税条件时）。
- **视同自产**：3+N合作生产型企业，外购成品须满足视同自产才能退税，否则只能免税。贸易型企业口径不适用于本履约
- **发票与退税**：专票对应退税；若后续出现无票货源，宜评估改走市场采购出口，勿与3+N退税混在同一主体既退税又核定
- **平台信息报送**：收入按订单销售额确认，费用单独核算。

**【行动建议】**（示例）
1. 列出外购成品清单，逐项对照视同自产条件，不满足的改为免税核算。
2. 核对专票品名、单位与报关单、收汇是否三流一致。
3. 核实产品HS及出口退税率。
4. 完善出口退税事后管理，备案单证定期自检。
5. 按平台订单销售额建立企业所得税申报口径，与信息报送对齐。
6. 若存在无票或普票货源，单独评估市场采购出口，不要与退税主体混用核定征收。

**【注意事项】**（示例）
- 本报告为一般性参考，不构成法律意见；具体实施前建议咨询专业财税顾问。
- 单次诊断仅针对当前阿里国际站及所提供信息。
- 如涉及专票、无票多货源，或者同一主体多平台运营，需要综合评估解决方案，可预约专家1v1咨询。
- 各地税局对视同自产和出口退税审核要点有差异，搭建前可咨询专家。
