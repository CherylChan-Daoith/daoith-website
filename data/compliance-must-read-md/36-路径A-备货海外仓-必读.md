## 特征与子类型

**特征**：

中国店+产品能退免税+非国际站+备货海外仓

**子类型 / 分类**：

- 【A1 有票可退税】：发货为平台海外仓 / 自发货（海外仓）/ 亚马逊FBA / 半托管（海外仓）/ POP（海外仓发货）/ Shopee海外仓 / FBL海外仓 等；问题4回复**委托货代出口**或**其他**；供应商能提供专票（或可取得），产品为普货或涉检且能退税。
- 【A2 无票/无法专票】：同上发货，出口为委托货代或其他；上游无票或仅普票且改专票困难，评估1039。
- 【A3 有票无票并存】：部分专票+部分无票/部分普票，须拆成两条通道，勿混成一句。
- 判定：中国店 + 产品能退免税 + 非国际站 + 委托货代出口或其他 → 走 A（默认兜底）。已正式报关的0110/9710/9810/1039走 Z，不要进 A。

## 风险思路与要点

**【A1/A2/A3共性】**

1. 委托货代出口即实务「买单出口」：报关单发货单位为货代，与经营主体不符，货、款、单三流不一致，税务机关难以认可该报关单用于退免税，存在视同内销补税风险。
2. 即使有专票、产品可退税，也不满足「自有抬头正式报关」这一退税硬条件。
3. 大陆主体信息报送与申报脱节。
4. 涉检商品未先办商检则无法正规报关。

**【A1】**

有票却走货代，退税利益完全落空，是当前最大瓶颈。

**【A2】**

无票叠加买单出口，既不能退税也不能正经免税，税负与稽查风险更高。

**【A3】**

有票无票混报时，退税与1039免税资格都可能被质疑。


## 解决方案思路与要点

**【A1】**

强制写「以自有抬头正式0110替代委托货代/买单出口」。专票+普货可退税时，plan.details 的 title 须含「0110出口+境外/香港公司」：供应商 → 进出口公司 → 境外/香港公司 → 店铺公司 → 境外消费者。优先0110，谨慎9810（实操退税不确定，须提示与税局沟通销售佐证与收汇）。报关抬头尽量为经营主体自己。仅有普票可沟通改专票；1%专票退税率也是1%。

**【A2】**

title 须含「1039出口+境外/香港公司」：供应商 → 个体户 → 香港公司。须核禁限：敏感/危化/0退税/液体/动植物食品不能走1039；商标专利查海关知识产权备案；含木商检、原木包装熏蒸；核定征收单个个体户连续12个月一般不超过500万，同一个人设立多个个体户出口需在个人所得税汇算清缴时合并缴纳个人所得税。

**【A3】**

有票走0110退税、无票走1039免税，分别写两条架构。

**共性：**

1. 贸易型企业进项品名/单位与报关单一致；生产型企业外购须视同自产才能退税，否则免税。
2. 大陆主体必须写信息报送，主体不一致时补采购再销售链路。
3. 涉检先商检再正式报关。
4. 人民币提现平台提示可能制约退免税收汇。
5. 年销售额≥5000万提示服务公司，≥1亿强调关联交易定价；可一句提示架构与首单退税周期较长。
6. 核实出口退税率。

- 委托货代出口=买单出口=货代抬头报关；**仅路径A**下须写「以自有抬头0110替代委托货代/买单出口」（Z已正式报关时禁止套用这句）。

- 大陆主体03须含境外/香港公司售店铺链路（采购再销售）。禁止把「0110出口+境外/香港公司」只丢在细则、概览却写无关事项。

- A 为兜底，优先级最低（7）。


## 方案样本（结构参考·禁止照抄画像）

> **示例样本**（结构参考；禁止照抄下列平台/销售额/画像）

**【诊断档案】**（示例）

- 销售平台：亚马逊
- 注册主体：中国大陆公司
- 发货方式：亚马逊FBA
- 出口方式：委托货代出口
- 供应商发票：部分专票+部分无票
- 产品类别：普货，能正常报关出口和退税
- 年销售额：2000-5000万

**【核心风险诊断】**（示例结构）

业务流程：部分专票+部分无票 → 中国大陆公司 → 委托货代出口 → 亚马逊FBA → 亚马逊 → 境外消费者
主要风险：当前最大瓶颈是委托货代出口（买单出口）导致报关抬头与经营主体脱节，三流不一致，无法满足退税四条件；同时部分无票采购进一步削弱进项抵扣，整体税负与合规风险较高

01 供应商发票和产品环节
- **专票与无票并存**：无票部分无法用于出口退税，企业所得税前扣除也可能受限
- **出口退税率核实**：产品为普货可退税，须逐项核实HS。可在本页左侧「查询出口退税率」核实

02 报关出口环节
- **委托货代导致三流不一致**：报关单发货单位为货代，物流、资金流、单证流脱节，难以用于退免税，存在视同内销补税风险
- **难以满足退税四条件**：无法以自有抬头正式报关，即使有专票且产品可退税，退税路径仍被阻断

03 境外销售环节
- **平台信息报送与主体一致性**：亚马逊推送店铺身份与交易信息，税局一般要求店铺公司申报销售收入和所得税；若后续出口主体、香港公司与店铺公司不一致，报送与申报会脱节。收入须按平台订单销售额确认，不得扣除平台费用

**【合规方案】**（示例结构）
您属于亚马逊FBA + 委托货代出口，核心合规路径是以自有抬头正式报关替代货代，并按有票/无票拆分退税与免税通道

01 供应商发票和产品环节
- 梳理专票，推动无票供应商补开专票
- 核实产品HS及出口退税率

02 报关出口环节
- 以自有抬头0110替代委托货代/买单出口
- 有票部分走0110出口+境外/香港公司
- 无票部分评估1039出口+境外/香港公司

03 境外销售环节
- 核对境外销售主体与店铺主体
- 按平台订单销售额确认收入
- **以自有抬头0110替代委托货代/买单出口**：当前货代抬头无法匹配退税主体，须改为经营主体自己作为0110发货单位，实现报关单、发票、资金流三流一致
- **0110出口+境外/香港公司**（有票部分）：国内供应商 → 进出口公司 → 香港公司 → 店铺公司 → 境外消费者。进出口公司以自有抬头0110报关出口给香港公司，凭专票申报出口退税。关联交易须符合独立交易原则
- **1039出口+境外/香港公司**（无票部分）：国内供应商 → 个体户 → 香港公司 → 店铺公司。1039无票免征增值税，个税可申请核定征收。单个个体户连续12个月一般不超过500万，须合理安排规模。出口前核禁限类及商标专利海关备案
- **平台信息报送与采购再销售**：架构落地后，若香港公司与亚马逊店铺主体不一致，增加香港公司从出口主体采购后再销售给店铺公司。收入按订单销售额确认，费用单独核算
- **关联交易前瞻**：年销售额2000-5000万，超过5000万可考虑服务公司，须提前规划转让定价并备妥同期资料

**【行动建议】**（示例）
1. 梳理供应商，区分专票与无票，优先推动无票补开增值税专用发票。
2. 注册或确认大陆进出口公司作为自有抬头，申请0110出口资质，替代委托货代。
3. 核实产品HS及出口退税率，确保有票部分可正常退税。
4. 评估无票部分是否适用1039，确认不涉禁限，并注册个体户；不要按销售额拆分多个体户。
5. 整理历史货代报关单据，与税局沟通过往税务处理。
6. 按平台订单销售额建立账务，核对店铺主体与香港公司是否需要采购再销售链路。

**【注意事项】**（示例）
- 本报告为一般性参考，不构成法律意见；具体实施前建议咨询专业财税顾问。
- 单次诊断仅针对当前亚马逊平台及所提供信息，若涉及多平台或业务变更需重新评估。
- 各地税局对1039核定征收及出口退税审核要点有差异，搭建前建议与当地税局沟通。
- 架构搭建与首单退税周期可能较长。
