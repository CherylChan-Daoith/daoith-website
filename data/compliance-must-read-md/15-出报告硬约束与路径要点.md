# 出报告硬约束与路径要点（诊断助手必读·精简版）

> **知识库用途**：道一诊断报告生成硬约束与路由总览。路径撰写细则见 `30–36-路径*-必读.md`，按 `report_path` **只检索当前一篇**整篇采信。
>
> **检索关键词**：诊断报告,出报告硬约束,核心风险诊断,合规方案,行动建议,注意事项,report_path,档案锁定,路径Y,路径D,路径X,路径Z,路径C,路径B,路径A
>
> **切块**：按 `##` 切块即可；本篇已精简，出报告时先读本篇再只召回命中路径的 30–36 一篇。

## 报告输出格式（强制）

用户可见报告**只能**用四章固定标题（禁止变体、禁止路径字母）：

1. `【核心风险诊断】`
2. `【合规方案】`
3. `【行动建议】`
4. `【注意事项】`

若上游要求 JSON，四键与上列一一对应（`risk` / `plan` / `actions` / `notes` 或等价字段），正文仍须是上述四章中文内容。禁止把本说明、路径字母或 JSON 键名写进用户可见正文。

### 四章版式（极简）

- **【核心风险诊断】**：先写「业务流程：…」一行（顺序：发票 → 主体 → 出口 → 发货 → 平台 → 境外消费者），再「主要风险：…」，其下用 `- **短标题**：说明` 列 3～5 条风险。禁止把「业务流程」「主要风险」写成列表项。
- **【合规方案】**：开篇一段普通正文点明画像与是否具备退免税条件；随后 3～6 条 `- **短标题**：说明`。禁止在本章用 `1. 2. 3.`。非定制／定制并列卡片**仅路径 B 需要时**使用。
- **【行动建议】**：连续同级 `1. 2. 3. …`，可执行清单。
- **【注意事项】**：项目符号；含一般性参考非法律意见、单次诊断单平台等。

### 跨章纪律

- 禁止 Markdown 表格、禁止外链 / 网址（含 `http(s)://`、`[](url)`）。
- 禁止对用户输出思考过程、英文提纲、工具调用痕迹；禁止空标题。
- 出口退税率统一写「可在本页左侧『查询出口退税率』核实」。
- 报告结尾可提示：「可以选择页面下方「专家1v1财税咨询服务」进行深度沟通。」（不要提问）
- 禁止输出「诊断档案确认」「以下方案由左侧生成」——直接从【核心风险诊断】起笔。

## 档案七字段锁定（强制）

诊断档案七字段——**平台 / 主体 / 发货 / 出口 / 发票 / 产品 / 销售额**——须**逐字锁定**写入业务流程与方案。

禁止改写示例：部分普票→部分无票；普货→0退税率/标识1/2；国内仓↔保税仓；销售额档位改写。档案已有出口方式时禁止写「未提供出口信息」。

## report_path 字母不得出现在用户可见字段

`report_path`（Y / D / X / Z / C / B / A）及「路径Y」「情形D」等**仅内部路由**。

用户可见的 risk / plan / actions / notes（及四章正文）**一律禁止**出现路径字母或内部情形编号。知识库中标注【仅内部参考】/【内部路由】的内容不得外泄。

## 决策树顺序（只选一条）

按下列顺序命中即停，未命中再往下；细节与撰写口径见对应 `30–36` 全文。

| 顺序 | report_path | 一句话命中 |
|------|-------------|------------|
| 1 | **Y** | 非中国店（境外主体） |

综合全部七字段交叉匹配，禁止只看单一维度下结论。

## 通用写作纪律（跨路径）

- 写 1039 / 个体户时：如需核定征收，单个个体户连续12个月一般不超过500万并合理安排规模；**禁止**建议按销售额拆分多个体户。
- **特殊商品标识（标识1/标识2）**：仅路径 D（0退税率）可写入用户可见报告；普货 / 涉检 / 其他路径一律禁止写标识1/标识2。
- **平台信息报送**：仅当店铺主体为中国大陆公司 / 中国个人 / 个体户时写入；境外主体（含香港公司、外籍个人、其他境外公司、南美/东南亚本土公司）**禁止**写平台报送、禁止把报送口径套到香港利得税。采购再销售链路仅适用于大陆店且以当前路径内部路由为准（C/D/X 等通常禁止）。
- 若检索结果不足或冲突：以本篇硬约束 + 当前路径 30–36 全文 + 用户已确认七字段为准，禁止因检索失败而空泛作答。
