# 出报告硬约束与路径要点（诊断助手必读）

> **知识库用途**：第八步生成诊断报告前强制检索。含**合规方案主逻辑**、内部路由、版式、信息报送/收入口径、路径 A/B/C 要点。按用户档案改写，禁止对用户输出「路径A/B/C」「情形一/二/三」。
>
> **检索关键词**：诊断报告,出口退免税,卡点,证据链,订单流,资金流,物流,免税,业务模式重构,境外主体,服务公司,关联交易,5000万,1亿,核心风险诊断,合规方案,路径A,路径B,路径C,0110,1039,1210,9610,9810

## 一、出报告检索顺序

1. 本篇（主逻辑 + 硬约束 + 命中路径要点）
2. `00-必须知道的知识点`（退税四条件、四套架构、（六）信息报送、（七）销售额分层）
3. 对应「问题X + 关键词」分篇
4. 命中的一篇【方案样本】路径 A/B/C —— 对齐结构与口径，**禁止照抄样本画像**
5. 实操附件按需

冲突时：用户已确认选项 + 本篇主逻辑 优先。

## 二、合规方案主逻辑（强制）

写作顺序必须是：**评退免税 → 点卡点 → 对症拆解 →（若仍无法退免税）证据链争免税 → 不认可则重构 → 大额分层建议**。

### 2.1 先评估是否符合出口退（免）税条件

退税四条件须**同时**满足才优先推退税路径（详见 `00`（一））：

1. 一般纳税人企业（主体侧）
2. 上游能提供增值税**专用发票**（小规模 1%/3% 专票对应退税率同）
3. 产品**非 0 退税率**
4. 能**正式报关**且尽量取得**自有抬头**报关单/清单（全托管由平台安排出口、委托货代非自有抬头、未报关小包等常构成卡点）

开篇【合规方案】须用一两句点明：当前**具备 / 部分具备 / 不具备**退免税条件。

### 2.2 指出目前没法出口退免税的卡点

在【核心风险诊断】中明确写出卡点（有几条写几条，勿写无关项），常见维度：

| 卡点类型 | 典型表现 |
|----------|----------|
| **出口报关** | 委托货代非自有抬头；小包未报关；全托管/平台安排出口无自有报关单 |
| **产品类型** | 0 退税率；商检未解决；海关备案商标/专利未获授权（侵权风险） |
| **发票类型** | 无票、仅普票、部分无票导致退税基础不完整 |
| **其它** | 个人账户收汇、三流不一致、提现仅人民币难满足收汇等 |

### 2.3 解决方案针对卡点逐一建议

【合规方案】每条卡片对应一个卡点或一组紧密相关卡点，例如：

- 报关卡点 → 转自主 **0110** / 评估 **1210·9610** / 核实平台单据（路径 C）
- 发票卡点 → 改开专票；无票评估 **1039** 或综试区无票免征（注意主体剥离）
- 商检卡点 → 先办商检再谈报关退税
- 主体/报送 → 架构后核对境外销售主体与店铺主体（仅自营出口场景可补采购再销售链路）

### 2.4 确实不符合出口退免税条件时

适用例：全托管平台安排出口、产品 0 退税率、产品侵权/未授权导致无法合规报关退税等。

**第一步（争免税）**：指导收集并留存完整证据链——**订单流、资金流、物流**（及平台结算/提现记录等），尽可能与主管税务机关申请按**免税**等口径处理。须写明「以税局最终认定为准，不可默认获批」。

**第二步（税局不认可）**：建议**业务模式重构**——引入**境外主体作为平台销售主体**（如香港公司等作为店铺注册主体），降低视同内销等增值税税负影响；复杂个案引导专家 1v1。

注意：

- 路径 C（平台安排出口）：可写「境外主体开店重构」，**禁止**写「香港公司从出口主体采购后再销售给大陆店铺公司」。
- 路径 A/B 自营出口且店铺仍为大陆主体、境外销售主体不一致时：仍可用「境外主体采购后再销售给店铺公司」补链（与「境外主体直接开店」不同，勿混淆）。

### 2.5 销售额分层（年销售额，人民币）

| 档位 | 方案/注意中须体现 |
|------|-------------------|
| **≥5000万**（含 5000万–1亿及更高） | 建议评估设立**服务公司**（如离岸服务外包增值税优惠、技术先进型服务企业等路径按适用性简述），优化**集团整体税负**；可引导专家测算，勿编造具体节税比例。 |
| **≥1亿** | 在 ≥5000万建议基础上，须明确提醒**关联交易定价管理**：关联公司之间定价须合理，不得将大部分利润留存于无实质经营的香港公司或核定征收主体，降低被反避税调查风险。 |

销售额未达档位则不必硬写服务公司/关联交易专段；达到则【合规方案】或【注意事项】至少一条覆盖。

## 四、报告版式（官网渲染依赖）

章节标题**只能**：`【核心风险诊断】` `【合规方案】` `【行动建议】` `【注意事项】`（相关追问可前置 `【变化点】` `【影响与注意事项】`）。

- **禁止**表格、外链、网址；退税率写「可在本页左侧『查询出口退税率』核实」。
- **禁止**「诊断档案确认」、路径/情形编号、阿里系/Temu 圈定对比外泄。
- 【核心风险诊断】：业务流程一行 → 主要风险一行 → 3～5 条 `- **短标题**：说明`（含卡点）。
- 【合规方案】：开篇点明退免税结论+卡点 → 3～6 条对症卡片；非定制/定制用并列卡片。
- 【行动建议】：同级 `1. 2. 3.`（可含：补证据链、改报关/发票、服务公司评估、关联交易制度等）。
- 结尾：可以选择页面下方「专家1v1财税咨询服务」进行深度沟通。

## 五、其它硬约束

1. 产品退税率以用户当轮为准；禁止增值税税率冒充出口退税率。
2. 大陆主体信息报送：风险进风险章、方案进方案章（见 `00`（六））；收入＝**平台订单销售额**。
3. 禁止编造文号/精确节税数字；复杂个案 + 专家1v1。
4. 档案已有出口方式时禁止声称「出口未知」。

## 六、路径A要点（海外仓）— 仍服从主逻辑

- 评四条件；货代抬头/无票/商检等写成卡点后对症拆。
- 委托货代 → 转自有抬头 **0110**；有票「**0110出口+香港公司**」；**9810**谨慎。
- 有票/无票拆分；无票评估 **1039+香港公司**。
- 0退税率/侵权未授权 → 走 2.4（证据链争免税 → 不认可则境外主体重构），勿空谈退税。
- 达销售额档位 → 服务公司 / 关联交易（见 2.5）。

## 七、路径B要点（自发货小包）— 仍服从主逻辑

- 未报关/无报关单为报关卡点 → **1210/9610** 对症；测算物流成本。
- 非定制 1210 备货；定制 1210 一日游或 9610。
- 无票+综试区：无票免征+核定；**退税与核定主体剥离**。
- 个人收汇 → 改公司账户。
- 无法转正式报关退税 → 2.4；达档位 → 2.5。

## 八、路径C要点（平台国内仓）— 仍服从主逻辑

- 默认难满足「自有抬头正式报关」→ 开篇写明不具备常规退税条件。
- 卡点：无自有报关单、可能提现限制、无票加重视同内销税负等。
- 对症：核实平台单据 → **订单/资金/物流证据链争免税** → 不认可则**境外主体作为平台销售主体**重构。
- 视同内销测算；无票改专票。
- **禁止**采购再销售补链；达档位 → 2.5。

### 内部参考（禁止输出给用户）

阿里系全托管或可凭清单与税局沟通免税；主要适用阿里系。对非阿里系用户正文只写「核实单据 + 证据链 + 与税局沟通」。

## 九、大陆主体强制条款摘要

- 风险：平台报送；店铺公司为销售收入与所得税申报主体；订单销售额口径。
- 方案 A/B：架构后主体一致性；不一致可补采购再销售 + 订单销售额确认收入。
- 方案 C：订单销售额确认收入；争免税/境外开店重构；**不写**采购再销售。
