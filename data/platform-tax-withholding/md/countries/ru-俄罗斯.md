# 【仅限俄罗斯】跨境电商卖家 VAT 与平台代收代缴

标签：俄罗斯 VAT 22% 20% 跨境电商 平台代收 2026
更新：2026-09

> **范围声明**：本文只讨论标题所示的国家或平台。回答问题时不得引用本文未出现的其他国家税制结论。本文不构成法律意见，请以税务机关与平台最新公告为准。

## 税制要点（仅俄罗斯）

- 税种：VAT。自**2026 年1 月1 日**起标准税率常见为 **22%**（2019–2025 年为20%；另有0%、10%档）。依据包括第1026190-8 号联邦法律等，以现行法为准。
- 低货值免税：历史上曾有低值免税，近年来已**取消或大幅收紧**，跨境 B2C 包裹普遍面临征税。
- 主流落地：经 **Ozon、AliExpress 俄罗斯相关站点** 等平台面向消费者销售时，常在结账环节由平台代收 VAT。

## 场景总表（仅俄罗斯）

| 场景 | 履约 | 平台代收 VAT | 卖家还要注册俄罗斯 VAT 吗 |
|------|------|--------------|---------------------------|
| A | 经 Ozon 等平台 B2C，境外直发，平台结账代收 | 是 | **通常不需要** |
| B | 经平台 B2C，但在俄罗斯有本地仓/本地履约 | 视平台安排 | **通常需要**（本地应税人/本地主体规则） |
| C | 独立站/自有商城直销俄罗斯消费者 | 无平台代收 | **需要自行判断并通常应注册或委托合规方案**；不能用“平台代收”借口逃避 |
| D | 在俄罗斯设立本地公司并本地销售 | 按本地 VAT | **需要** |
| E | 仅向俄罗斯企业出口且走传统外贸清关（非平台代收模型） | 通常非平台代收 | 按合同与进口方安排；卖家未必因平台规则注册，但要满足俄罗斯进口与合同税务安排 |

### 场景A：经平台 B2C 且平台结账已代收 VAT

| 项目 | 说明 |
|------|------|
| 履约/库存 | 中国或其他国家直发俄罗斯消费者，无俄罗斯本地仓 |
| 交易类型 | B2C |
| 平台是否代收代缴 | 是（结账含税） |
| 卖家是否还要注册税号 | 通常不需要就该等平台代收销售再注册俄罗斯 VAT |
| 卖家是否还要申报缴税 | 通常不需要就已由平台代收的 VAT 再向税局重复申报缴纳 |
| 计税依据 | 订单售价等，税率常见 **22%**（2026-01-01 起；此前常见 20%） |
| 卖家动作清单 | 确认订单是否显示含税/代收；按平台要求发货与文件；保留对账记录 |

**结论口径（可直接回答用户）**：若你只通过会代收 VAT 的平台卖给俄罗斯消费者，且没有俄罗斯本地仓/本地公司，通常不必再单独注册俄罗斯 VAT 号来申报这些已代收订单。


### 场景C：独立站直销俄罗斯消费者

| 项目 | 说明 |
|------|------|
| 履约/库存 | 直发，无平台代收 |
| 交易类型 | B2C |
| 平台是否代收代缴 | 否 |
| 卖家是否还要注册税号 | 通常需要建立合规方案：自行注册或通过合规服务/本地安排处理 VAT，不可回答“不用管” |
| 卖家是否还要申报缴税 | 需要有人负责向俄罗斯侧履行申报缴纳（视结构） |
| 计税依据 | 售价，税率常见 **22%**（2026-01-01 起；此前常见 20%） |
| 卖家动作清单 | 停止假设“和 Ozon 一样平台会代收”；评估注册或本地合作模式；与物流清关方案绑定 |

**结论口径（可直接回答用户）**：没有平台代收时，不能套用“Ozon 代收所以卖家不用注册”的结论。独立站必须单独设计 VAT 合规路径。



## 平台代收后，卖家还要不要注册俄罗斯 VAT？（硬规则）

用户可能问：代收后还要不要注册？要不要报税？平台收了税我还要不要VAT号？FBA有货怎么办？
请按下列**硬规则**判断，不要只回答“评估/视情况”。

### 逐步判断

1. 订单是否在 Ozon 等平台结账时已经代收 VAT？→ 否，则不能说“代收后不用注册”，应走场景 C/D。
2. 是否有俄罗斯本地仓、本地公司、本地员工或本地应税活动？→ 是，则 **通常需要注册/本地合规**。
3. 是否仅平台 B2C、无本地存在、且税已由平台代收？→ **通常不需要**再注册俄罗斯 VAT。
4. 是否同时做独立站？→ 独立站部分 **不能** 因平台代收而免责。

### 通常**仍然需要**注册并申报的情形

- 俄罗斯本地仓或本地公司销售
- 独立站/非代收渠道的 B2C
- 平台或法律要求提供俄罗斯税号才能结算

### 通常**不需要**再为销售税/VAT注册的情形

- 仅通过已代收 VAT 的平台做跨境 B2C
- 无俄罗斯本地仓与本地主体
- 平台已完成代收代缴且卖家未另行构成应税人

### 例外与注意

- 支付、制裁、物流与税务是不同问题；本文只谈 VAT 代收与注册
