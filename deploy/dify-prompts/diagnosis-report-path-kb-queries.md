# 诊断报告：路径判定 + 按路径知识检索

> 流程：问诊 Agent 根据 7 问**只定路径 A/B/C/D（不读库）** → 调用工具并传入 `report_path` → Workflow 用对应 `kb_query` 做知识检索 → LLM 写 JSON → Code。

---

## 1. 问诊 Agent：路径判定规则（内部，勿对用户说出路径字母）

采信已确认的发货 / 出口 / 产品类别，**只选一条**：

| 路径 | 判定条件（满足即定，按表从上到下优先） |
|------|----------------------------------------|
| **D** | 产品为「0退税率…」或「海关备案商标但暂未获得授权」 |
| **C** | 发货为平台国内仓 / 全托管（国内仓）/ 半托管（国内仓）/ 供货 SHEIN（国内仓）等，**或** 出口已为「由平台安排出口」 |
| **B** | 出口含小包 9610/1210/未报关；或国内直发/便捷发货且走小包清单 |
| **A** | 其余：海外仓 / FBA / FBL / 正式报关 0110/9710/9810、1039、委托货代等（默认） |

定路径后调用 `generate_diagnosis_report`，参数至少包含：

- `diagnosis_archive`：完整【诊断档案】
- `report_path`：`A` / `B` / `C` / `D`（必填）
- `user_reply`：用户最后一轮答复（可选）
- `follow_up_changes`：变化点（追问改档时可选）

**禁止**为定路径去检索知识库；**禁止**向用户解释「你是路径 A」。

---

## 2. Workflow 开始节点变量

| 变量 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `diagnosis_archive` | 文本 | 是 | 诊断档案全文 |
| `report_path` | 文本 | 是 | `A` / `B` / `C` / `D` |
| `user_reply` | 文本 | 否 | 最后答复 |
| `follow_up_changes` | 文本 | 否 | 变化点 JSON/文本 |

---

## 3. 画布（推荐）

```text
开始
  →（可选）模板/代码：按 report_path 选出 kb_query
  → 知识检索（查询文本 = kb_query；挂必读+实操+退税率等库；Top K 6；可开 Rerank）
  → LLM（写 JSON；System 用 diagnosis-report-workflow-prompt.md）
  → Code
  → 结束
```

若暂无模板节点：知识检索的查询文本可用「条件分支」四路，每路粘贴下方对应 query，或用一个 Code 节点 `if path=="A": return query_a`。

---

## 4. 四条路径的 kb_query（原样可贴）

公共前缀（每条都带）：

```text
出报告硬约束与路径要点；必须知道的知识点；
```

### 路径 A（海外仓 / 正式报关系）

```text
出报告硬约束与路径要点；必须知道的知识点；
方案样本 路径A 海外仓 正式报关 0110出口+香港公司 1039出口+香港公司 委托货代 买单出口 9810；
信息报送 平台订单销售额；发货海外仓 FBA FBL；
```

再拼上：`{{#start.diagnosis_archive#}}`（或档案摘要）。

### 路径 B（自发货小包）

```text
出报告硬约束与路径要点；必须知道的知识点；
方案样本 路径B 自发货小包 1210出口备货至保税区 1210保税区一日游 9610跨境电商零售出口；
小包快递 未报关 国内直发；
```

+ `diagnosis_archive`

### 路径 C（平台国内仓）

```text
出报告硬约束与路径要点；必须知道的知识点；
方案样本 路径C 平台国内仓 由平台安排出口 全托管 半托管国内仓；
禁止0110香港 禁止1039香港 平台单据 视同内销或免税沟通；
```

+ `diagnosis_archive`  
（本路径检索 **不要** 强调「0110出口+香港公司」方案样本为主命中。）

### 路径 D（0 退税率 / 商标未授权）

```text
出报告硬约束与路径要点；必须知道的知识点；
方案样本 路径D 无法退免税 0退税率 特殊商品标识 视同内销 出口免税 进项转出；
海关备案商标 暂未授权；出口退税率 特殊商品标识；
```

+ `diagnosis_archive`  
（建议知识检索已勾选「海关编码和出口退税率」。）

---

## 5. 知识检索勾选库

与出报告一致即可：

- 必挂：`合规解决方案必读文件`
- 建议：`跨境电商实操知识`（若独立）、`海关编码和出口退税率`
- 按需：`出口退税法规和实操`、`DAOITH跨境电商知识库`

Top K **6**；Rerank 可用；Score 阈值可先关。
