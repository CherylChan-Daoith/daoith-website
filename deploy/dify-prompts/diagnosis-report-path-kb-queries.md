# 诊断报告：路径判定 + 按路径知识检索

> 流程：问诊 Agent 定路径 → Workflow **必返**（`00` + **仅当前路径** `30–36`）+ 可选 `15` → LLM 写 JSON → Code。  
> **已删除**旧方案样本 `20/21/22/23`；禁止再检索。路径细则在「路径*-必读」全文，不在提示词里展开。

## 0. 检索硬要求

| 优先级 | 材料 | 作用 |

| **必返 ①** | `00-必须知道的知识点` | 通用知识点——**所有路径共用** |

## 1. 问诊 Agent：路径判定（内部，勿对用户说出路径字母）

**口径**：中国店 = 中国大陆公司 / 中国个人 / 个体户；可退免税产品 = 普货可退税或涉检（非 0 退税率、非商标未授权）。

**顺序强制（命中即停）**：

| 顺序 | 路径 | 判定条件 |
|------|------|----------|
| 1 | **Y** 非中国店 | 主体 = 中国香港公司 / 外籍个人 / 其他境外公司 / 南美洲本土公司 / 东南亚本土公司 |
| 2 | **D** 产品无法退税 | 中国店 + 产品 = 0 退税率 **或** 海关备案商标暂未获得授权 |
| 3 | **X** 特殊平台 | 中国店 + 可退免税 + 平台 = 阿里国际站（发货自营 / 一达通 3+N 或 2+N / 市场采购 / 便捷发货） |
| 4 | **Z** 已合规出口 | 中国店 + 可退免税 + 非国际站 + 出口 = 正式报关（0110/9710/9810/1039）**或** 小包快递出口（9610/1210）【已报关清单】 |
| 5 | **C** 平台安排出口 | 出口 = 由平台安排出口（含国内仓跳问自动记入） |
| 6 | **B** 自发货小包 | 出口 = 小包快递出口（未报关） |
| 7 | **A** 备货海外仓 | 出口 = 委托货代出口 **或** 其他（兜底） |

定路径后调用 `generate_diagnosis_report`：

- `diagnosis_archive`：完整【诊断档案】（七字段原样）
- `report_path`：`Y` / `D` / `X` / `Z` / `C` / `B` / `A`
- `user_reply`、`follow_up_changes`（可选）

**禁止**为定路径检索知识库；**禁止**向用户解释路径字母。

## 4. 各节点查询文本

### 4.0 必须知道（所有路径相同）

```text
00-必须知道的知识点
必须知道的知识点
```

Top K **8～12**。建议元数据：`document_name` 包含 `00-必须知道的知识点`。

### 4.1 可选硬约束

```text
15-出报告硬约束与路径要点
出报告硬约束与路径要点
```

### 4.2 路径必读（七选一，Code 映射）

```python
def main(report_path: str) -> dict:
    p = (report_path or "").strip().upper()
    m = {
        "Y": "30-路径Y-非中国店-必读",
        "D": "31-路径D-产品无法退税-必读",
        "X": "32-路径X-特殊平台-必读",
        "Z": "33-路径Z-已合规出口-必读",
        "C": "34-路径C-平台安排出口-必读",
        "B": "35-路径B-自发货小包-必读",
        "A": "36-路径A-备货海外仓-必读",
    }
    name = m.get(p, m["A"])
    return {
        "path_query": name,
        "document_name": name,  # 供元数据筛选
    }
```

知识检索节点：query 绑 `path_query`；**元数据筛选（推荐）**：

- 筛选模式：手动
- 条件：`document_name` **是** / **包含** → `{{ document_name }}`（或各分支写死对应文件名）
- 效果：先按文件过滤再向量检索，其它路径必读进不来

若界面无元数据筛选：至少用精确文件名做 query + 高 Top K，试跑确认来源文档。

### 4.3 补充（造差异）

从档案抽平台/主体/发货/出口/发票/产品/销售额拼 query；**不要**再命中其它路径 `30–36` 全文。产品含品名/HS 或路径 D 时，可并行挂退税率库。

## 5. 知识检索勾选库与参数

- 必挂：`合规解决方案必读文件`（须已收录 `00`、`30–36`；可选 `15`）
- **不要**再依赖已删除的 `20–23`
- 必返：Top K **8～12**；补充：**6～8**
- 索引建议：`00` 与各路径必读尽量整篇或大块入库

### 5.1 元数据锁文档（路径节点必做）

| 做法 | 怎么配 |
|------|--------|
| **精确标题 query** | query 只写当前路径必读文件名 |
| **元数据筛选（推荐）** | `document_name` 是/包含当前路径文件名 |

两路可叠加。
