二、本站涉及的人工智能功能

本站提供的人工智能相关功能主要用于跨境电商财税咨询辅助，包括但不限于：

  • AI 智能合规方案生成与问答辅助；
  • HS 编码退税率 / 关税税率查询辅助；
  • 合规税负测算辅助说明；
  • 站内智能客服对话辅助。

上述功能均属于文本生成与信息辅助类应用，不提供人脸生成、语音合成、视频换脸等深度合成（深度伪造）内容生成服务。

三、算法来源与接入方式

本公司不自研、不训练基础大语言模型或深度合成算法。本站人工智能能力通过合法合规的第三方人工智能服务接口（API）接入调用实现，具体为：

  • 应用编排与调用平台：Dify（自托管应用编排平台），用于对话与工作流编排；
  • 大语言模型服务：经 Dify 接入的第三方大语言模型服务（包括但不限于 DeepSeek 等公开可商用的大语言模型 API）；
  • 调用方式：服务器端发起 API 请求，按服务商协议与计费规则使用；不将用户数据用于训练本公司自有基础模型。

相关算法服务提供方负责其模型的研发、备案与安全评估；本公司作为接入调用方，按约定用途使用其文本生成能力，用于财税咨询场景下的信息辅助。

四、接入协议与前置许可材料说明

本公司与上述第三方人工智能服务提供方之间，就算法接入与调用订有相应的服务协议 / API 使用合同（含在线服务条款、订单或书面协议等）。

在公安机关网站安全管理系统（前置许可）办理时，本公司将按审核要求另行上传：

  • 与第三方 AI / 大模型服务商的接入调用协议或合同；
  • 算法来源说明（与本页内容一致）；
  • 其他按当地公安机关要求补充的材料。

本页为面向公众的算法来源公示；合同原件或扫描件在管理系统中提交，不以网页替代。

五、深度合成业务说明

根据《互联网信息服务深度合成管理规定》等规定，本站当前业务不属于面向公众提供深度合成内容生成服务的情形。如后续开展须履行算法备案或安全评估的业务，本公司将依法办理相关手续并更新本说明。
